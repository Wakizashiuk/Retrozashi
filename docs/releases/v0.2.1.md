**Retrozashi 0.2.1: one-click "Check Claude app" when the Claude app can't see Retrozashi.**

> ⚠️ **Pre-release.** Built and self-tested on Windows in CI, but not yet run on a real gaming PC with these
> emulators.

## What's new
- **Check Claude app** button (and `Retrozashi.exe --doctor`). It finds out why the Claude desktop app doesn't
  know about Retrozashi and says so in plain words:
  - Is the Claude desktop app installed (installer or Microsoft Store build)?
  - Is Retrozashi in its settings, pointing at an exe that still exists? Is that settings file valid?
  - Does Retrozashi actually start the way Claude starts it, and how fast?
  - Was Claude already open when Retrozashi was added (so it needs a full quit from the tray)?
  - What does Claude's own log (`mcp-server-retrozashi.log` / `mcp.log`) say?
- **Fix it** re-registers Retrozashi. **Copy report** puts the whole report, log lines included, on the clipboard.
- **Network drives:** if Retrozashi itself runs from a NAS or mapped drive, *Use the Claude app* copies it to
  `%LOCALAPPDATA%\Programs\Retrozashi` and registers that copy. Emulators on a NAS are fine as they are.

## Get started
1. Download **`Retrozashi-v0.2.1-win64.zip`** below, unzip it **on this PC** and run `Retrozashi\Retrozashi.exe`.
2. Choose **Use the Claude app**, then fully quit the Claude app (tray icon → Quit) and reopen it.
3. Claude still doesn't see it? Press **Check Claude app** in Retrozashi's window.
