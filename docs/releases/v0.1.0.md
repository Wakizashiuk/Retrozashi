First preview build of **Retrozashi**: talk to your emulators. It configures and controls **PCSX2, DuckStation,
Dolphin, RPCS3, Eden and RetroArch** by voice or text, with setup for remote play through **Moonlight + Vibepollo**.

> ⚠️ **Pre-release.** It's built and self-tested on Windows in CI, but hasn't yet been run on a real gaming PC
> with these emulators. Expect rough edges, and please report what you find.

## Download & run
1. Download **`Retrozashi-v0.1.0-win64.zip`** below and unzip it anywhere (e.g. `C:\Tools\Retrozashi`).
2. Run `Retrozashi\Retrozashi.exe`. Windows SmartScreen may warn about an unsigned app: *More info → Run anyway*.
3. Paste your Anthropic API key when asked. It's stored in Windows Credential Manager.
4. Follow **[docs/FIRST_RUN.md](https://github.com/Wakizashiuk/Retrozashi/blob/main/docs/FIRST_RUN.md)**.

Optional: check the download with `Get-FileHash .\Retrozashi-v0.1.0-win64.zip -Algorithm SHA256` against the
`.sha256` file.

## What's in it
- **Three ways to control an emulator:** direct config edits (any section, with a backup before every write),
  Windows UI Automation for settings dialogs, and Claude Computer Use (screenshots, mouse and keyboard) as a
  fallback.
- **Per-game overrides** for every emulator, with game IDs read from disc images, playlists and game lists.
- **Learns your builds:** it changes an option in the emulator's own window, sees what was written, and
  remembers the value.
- **Guides** for controllers (DualSense/DS4, 8BitDo), upscaling, per-game settings and streaming.
- **Moonlight + Vibepollo:** makes an emulator stream-ready on request, and keeps a controller set per virtual
  pad, switched automatically at every stream start.
- **Profiles**, **Undo**, local push-to-talk voice (faster-whisper), and a **Ctrl+Alt+K** kill switch.

## Known limits
- Some setting values (e.g. Eden's resolution options) are hints until learned on your PC.
- Compressed images (.chd, .rvz, .cso) don't give up their game ID. The emulator's Properties window is used
  instead.
- The exe is unsigned, so SmartScreen may warn.
