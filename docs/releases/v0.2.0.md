**Retrozashi 0.2.0: use it with the Claude desktop app, no API key needed.**

> ⚠️ **Pre-release.** Built and self-tested on Windows in CI, but not yet run on a real gaming PC with these
> emulators.

## What's new
- **Claude app mode (MCP).** Retrozashi plugs into the **Claude desktop app** as a tool server. With a Claude
  Pro/Max plan there's **no API key and no per-use billing**. Chat with Claude there (*"Using Retrozashi, set
  Eden to 2x resolution"*) and it uses every Retrozashi tool:
  - config search and edit, per-game overrides, guides
  - profiles, controller sets and the Vibepollo sync
  - UI Automation, plus screen, mouse and keyboard control of emulator windows
- **First-run choice:** *Use the Claude app* (recommended) or *Enter an API key*. There's also a **Use in Claude
  app** button, or run `Retrozashi.exe --install-claude-app`.
- **Safety carries over:** Ctrl+Alt+K halts mouse and keyboard control. Claude must ask you before resuming,
  and closing a running emulator still asks Yes/No.

## Get started
1. Download **`Retrozashi-v0.2.0-win64.zip`** below, unzip it and run `Retrozashi\Retrozashi.exe`.
2. Choose **Use the Claude app**, then fully quit and reopen the Claude desktop app.
3. Follow [docs/FIRST_RUN.md](https://github.com/Wakizashiuk/Retrozashi/blob/main/docs/FIRST_RUN.md).
